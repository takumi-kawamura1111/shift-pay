# シフト給与計算

コマ数・授業時間・事務時間・会議・交通費を入力すると、月の給与見込みを自動で計算するスマホ向けWebアプリです。

## 機能

- 勤務日ごとに入力：コマ数、コマ以外の授業時間、事務時間、会議（回数または時間）、交通費、その他手当、メモ
- 月ごとの合計・内訳（授業給／事務給／会議給／交通費／手当）・出勤日数・総コマ数・勤務時間
- 年間累計（交通費込み）と年収目標（例：130万円）までの残り額
- 前の勤務を「別の日にコピー」
- データは端末のブラウザ（localStorage）に保存。JSONで書き出し・読み込みできます
- ホーム画面に追加するとアプリのように全画面で使え、オフラインでも開けます

## GitHub Pagesで公開する

1. GitHubでリポジトリ（例：`shift-pay`）を作成し、このフォルダの中身をpushする
2. リポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして保存
3. 1〜2分後に `https://<ユーザー名>.github.io/shift-pay/` で開けます

## スマホのホーム画面に追加

- **iPhone（Safari）**：共有ボタン →「ホーム画面に追加」
- **Android（Chrome）**：メニュー →「ホーム画面に追加」／「アプリをインストール」

## 注意

- データは端末ごとに保存されます。別の端末とは共有されず、ブラウザのデータを消すと消えます。
- iPhoneでは、Safariで開いて「ホーム画面に追加」から使うのが一番消えにくい使い方です（Safariのタブや他のブラウザで開くと、しばらく開かなかったときに消えることがあります）。Safariとホーム画面のアプリは保存場所が別です。
- 最後の書き出しから30日たつと、画面上にバックアップのお知らせが出ます。iPhoneでは共有シートから「ファイル」やiCloud Driveに保存できます。
- 授業給は「授業の時給 ×（コマ数 × 1コマの時間 ＋ コマ以外の授業時間）÷ 60分」で計算します（1コマ80分・時給1,200円なら1コマ1,600円）。
- 時給で計算する分（授業・事務・会議）は、1日ごとに1円未満を切り捨てています。
- 計算結果は見込み額です。税金や社会保険料は差し引いていません。

## 更新したとき

`sw.js` の `CACHE` の名前（例：`shift-pay-v1` → `shift-pay-v2`）を変えてからpushすると、古いキャッシュが確実に入れ替わります。

## データベースに保存する（Neon + Cloudflare Worker）

salary-tracker と同じ Neon のデータベースに、`shift_pay_entries`（勤務記録）と `shift_pay_settings`（設定）のテーブルを作って保存します（テーブルは初回に自動で作られます）。
アプリから直接データベースにはつながず、間に中継役の Cloudflare Worker（`worker/worker.js`）を置きます。データベースのパスワードは Worker の中だけに保存します。

1. Cloudflare で **Workers & Pages → Create → Worker**（Hello World）を作る。名前は例：`shift-pay-api`
2. **Edit code** で中身を `worker/worker.js` に置き換えて **Deploy**
3. Worker の **Settings → Variables and Secrets** に次を追加（種類は Secret）
   - `DATABASE_URL`：salary-tracker と同じ Neon の接続文字列
   - `APP_PASSPHRASE`：アプリに入れる合言葉（長めのものにする）
4. アプリの 設定 →「データベースに保存」に Worker のURL（`https://shift-pay-api.〇〇.workers.dev`）と合言葉を入れて「接続して同期」

- 変更はまず端末に保存し、裏でデータベースに送ります。オフラインのときは、つながったときに送ります。
- 同じ記録を2台で変更した場合は、あとから変更したほうが残ります。

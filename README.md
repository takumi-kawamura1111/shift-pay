# 給与見込み計算

出勤日数とコマ数を入れると、その月の給与の目安を計算するスマホ向けWebアプリです。

https://takumi-kawamura1111.github.io/shift-pay/

## 使い方

1. ⚙︎（設定）で次を入れて保存する
   - 授業の時給、1コマの時間（分）
   - 1日あたりの交通費
   - 会議の時給
   - 事務給（「出勤1日ごと」か「1か月ごと」を選ぶ）
2. 画面で出勤日数・コマ数・会議の時間（分）を入れると、給与の目安と内訳がすぐに表示される

## 計算方法

- 授業給 ＝ 授業の時給 × 1コマの時間 × コマ数 ÷ 60分（1円未満切り捨て）
- 交通費 ＝ 1日あたりの交通費 × 出勤日数
- 会議給 ＝ 会議の時給 × 会議の時間（分）÷ 60分（1円未満切り捨て）
- 事務給 ＝「出勤1日ごと」なら 金額 × 出勤日数、「1か月ごと」なら金額のまま（出勤した月だけ）
- 税金・社会保険料は引いていません

設定と最後に入れた日数・コマ数・会議時間は、端末のブラウザに保存されます。

## スマホのホーム画面に追加

- **iPhone（Safari）**：共有ボタン →「ホーム画面に追加」
- **Android（Chrome）**：メニュー →「ホーム画面に追加」
